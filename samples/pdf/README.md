# 转换产物

`samples/ceb/` 里每个样本经 `ceb2pdf` 转换后的 PDF。

## 这里只跟踪一个子集

全部 18 份合计约 **74 MB**（最大的两份 25 MB 和 22 MB），不适合进 git 历史。
PDF 是**派生物**——有对应的 `.ceb` 就能重新生成：

```sh
ceb2pdf samples/ceb/*.ceb -o samples/pdf/
```

所以仓库里只保留 10 份小体积样本，覆盖各类容器版本与加密模式：

| 加密模式 | 文件 |
|---|---|
| 3DES-OFB (`0x80000001`) | 7 份 `moa-*` / `zys-*` / `zzj-*`（容器 `2.50f` / `2.50w`），外加 1 份 v3 容器 + Maker 5.0 |
| 3DES-CFB64 (`0x80000002`) | `zj-gov-cn-2012`、`wuhan-gov-cn-2020`（容器 `2.50U`） |

未跟踪的 8 份：两份 20 MB+ 的湖南省政府公报与农业农村部文件、两份 4-6 MB 的
公报、Adobe《PDF Reference》测试件（4.9 MB，第三方文档），以及国网公文。

## 国网公文

**不入库。** `.gitignore` 里点名排除。本地转换产物仍在，只是不上传。

## 这些文件是什么

除 Adobe 那份测试件外，均为中国大陆政府网站公开发布的公文附件
（农业部/农业农村部、湖南省政府公报、浙江省政府、武汉市政府），
原件即公开可下载，转换只改变封装格式。来源 URL 见 [`../README.md`](../README.md)。
