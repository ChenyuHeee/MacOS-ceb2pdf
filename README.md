# ceb2pdf

把方正 Apabi 的 `.ceb` 电子书转成 PDF 的 macOS 命令行工具。无损、轻量、无需 Wine。

## 为什么无损

CEB 不是一种独立的版式格式 —— 它是一个被两层弱加密包裹的**标准 PDF**：

```
Founder CEB 容器
└── 段 3 ──> Founder-RC4（整体，每 64 KiB 重置状态）
             └── 标准 PDF
                 └── 各 stream ──> 3DES-OFB（每 256 字节重置 IV）
```

所以转换不需要渲染引擎、不需要处理中文字体、不需要 OCR。
解开两层加密、抹掉 `/Encrypt` 标记，得到的就是原始 PDF 本身。

因为 OFB 是流密码、长度不变，整个过程可以**原地**完成，PDF 的 xref 偏移
全部保持有效，不需要重写文件结构。

格式细节见 [FINDINGS.md](FINDINGS.md)。

## 范围

仅处理密钥完整存放在文件自身内的 CEB —— 无授权服务器、无用户凭证绑定。
这属于格式层面的混淆，目的是互操作性。
带真实授权绑定的文件（如图书馆借阅本）应被检测并拒绝。
